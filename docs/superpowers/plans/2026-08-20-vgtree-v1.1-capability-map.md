**Goal:** Add a strict Capability Map 1.0 schema, semantic validator, deterministic compiler, CLI, public schema mirror, and package fixture without changing workflow state behavior.

**Architecture:** A new `vgtree.capability` module owns map loading, SHA-256 binding, semantic checks, interface warnings, and compilation into the existing task contract plus additive planning fields. This delivery stops before state initialization of `ADVISORY` or `REQUIRED` maps; state schema 2.1 is the next plan.

**Tech Stack:** Python 3.10+, standard library, jsonschema Draft 2020-12, unittest, existing VGTREE JSON result envelope

**Spec:** `docs/superpowers/specs/2026-08-20-vgtree-v1.1-coverage-evidence-design.md`

## Global Constraints

- Existing task files remain valid.
- Existing schema-2.0 state behavior remains unchanged in this delivery.
- Core code makes no network call and emits no telemetry.
- Unknown fields fail schema validation.
- IDs use `^[A-Za-z0-9][A-Za-z0-9._-]*$` and existing count/string bounds.
- Map compilation never overwrites an existing output.
- Same map bytes and compiler version produce byte-identical normalized task JSON.
- The source digest is SHA-256 over exact input bytes, not reparsed JSON.
- `PRE_EXECUTION` constraints must be enforced by real P0 dependency edges.
- No third-party agent framework or MCP dependency is added.

~~~python
"""Directed acyclic graph helpers shared by VGTREE validators."""

from __future__ import annotations

from collections import deque


def has_cycle(graph: dict[str, list[str]]) -> bool:
    indegree = {node: 0 for node in graph}
    dependents: dict[str, list[str]] = {node: [] for node in graph}
    for node, dependencies in graph.items():
        for dependency in dependencies:
            if dependency not in graph:
                continue
            indegree[node] += 1
            dependents[dependency].append(node)
    ready = deque(node for node, count in indegree.items() if count == 0)
    visited = 0
    while ready:
        node = ready.popleft()
        visited += 1
        for dependent in dependents[node]:
            indegree[dependent] -= 1
            if indegree[dependent] == 0:
                ready.append(dependent)
    return visited != len(graph)
~~~

Import `has_cycle` in `validation.py`, replace `_has_cycle(graph)`, remove the old function, and remove the unused `deque` import.

~~~python
def compile_capability_map(
    value: dict[str, Any], *, source_digest: str
) -> GuardResult:
    report = validate_capability_map(value)
    if not report.valid:
        return GuardResult(
            "FAIL",
            "CAPABILITY_MAP_INVALID",
            "Capability Map failed validation.",
            {"validation": report.as_dict()},
        )
    if not re.fullmatch(r"sha256:[0-9a-f]{64}", source_digest):
        return GuardResult(
            "FAIL",
            "CAPABILITY_SOURCE_DIGEST_INVALID",
            "source_digest must be a lowercase SHA-256 digest.",
        )
    task = {
        "task_id": value["task_id"],
        "title": value["title"],
        "description": value.get("description", value["goal"]),
        "signals": copy.deepcopy(value["signals"]),
        "branches": [_compile_branch(item) for item in value["modules"]],
    }
    for optional in ("explicit_class", "specialized_match"):
        if optional in value:
            task[optional] = copy.deepcopy(value[optional])
    if value["wide_pass_policy"] != "OFF":
        task["capability_map"] = {
            "map_version": value["map_version"],
            "source_digest": source_digest,
            "wide_pass_policy": value["wide_pass_policy"],
            "cross_cutting_constraints": copy.deepcopy(value["cross_cutting_constraints"]),
            "final_acceptance_matrix": copy.deepcopy(value["final_acceptance_matrix"]),
        }
    return GuardResult(
        "PASS",
        "CAPABILITY_MAP_COMPILED",
        "Capability Map compiled into a task specification.",
        {"task": task, "warnings": _interface_warnings(value)},
    )
~~~

`_compile_branch` maps every field from spec section 7.5. For `OFF`, emit only original v1.0 branch fields so the task initializes as state 2.0. Do not mutate caller data.
