# Privacy Policy

Effective date: 2026-08-20

VGTREE collects **no telemetry**. Its public website uses no analytics, cookies, remote fonts, or VGTREE account.

VGTREE is local-first software. The Python package and CLI do not collect telemetry, create user accounts, operate a hosted service, or transmit vault and workflow data to the VGTREE maintainers.

Workflow state, evidence, plans, receipts, and Obsidian starter files remain at paths selected by the user. Detailed receipt files are stored locally below a receipt root selected by the user; compact evidence may retain a local reference and SHA-256 digest. The core engine makes no network calls.

The OpenAI plugin contains Skills only. It declares no MCP server, app, hook, authentication flow, or external data connector. When a user runs VGTREE through ChatGPT, Codex, GitHub, Obsidian, or another third-party product, that product's own privacy terms and data handling apply.

Users are responsible for excluding secrets and private material from public repositories, issue reports, examples, and evidence references. Removing local VGTREE data is performed by the user through normal filesystem controls; VGTREE operates no server-side copy to delete.

Privacy questions may be raised through the repository's public support channel without including private data.
