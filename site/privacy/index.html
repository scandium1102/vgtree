Privacy by architecture, not by account settings.

VGTREE 1.1 is local-first software and a Skills-only plugin. It has no VGTREE account, hosted service, or telemetry pipeline.

What VGTREE does not collect

The VGTREE maintainers receive no telemetry, no analytics, no cookies, no uploaded workflow state, no Obsidian vault content, and no Tool Receipts through the VGTREE software or this website.

This static website uses no account, forms, JavaScript tracking, remote fonts, or advertising identifiers.

Local Engine data

The optional Python Engine reads files you explicitly name and writes only to explicit local outputs. These may include task specifications, workflow state, Capability Maps, evidence records, Tool Receipts, and Obsidian audit or plan results.

Tool Receipts remain local sidecars. Compact evidence may record an exact-byte SHA-256 digest and a local reference. VGTREE does not transmit those files or digests to a VGTREE-operated service.

Skills-only mode

The Skills-only plugin contains static instructions, schemas, references, templates, and assets. It does not auto-install the Engine and does not connect to a VGTREE backend. The ChatGPT or Codex host may process the prompts and files you choose to provide under the host provider’s own privacy terms.

Obsidian boundary

VGTREE 1.1 can audit or plan an existing vault from local paths. It does not automatically apply, move, rename, rewrite, or delete existing vault content. Scaffold operations are restricted to a new or empty destination.

Third-party surfaces

GitHub, PyPI, OpenAI, your operating system, Python installer, agent host, and Obsidian are separate services or software. Their own privacy policies apply when you use them. VGTREE does not control their logging or retention.

Support and changes

Public support is provided through GitHub Issues. Do not include secrets, identity documents, private vault notes, or access tokens in an issue.

Material policy changes will be versioned in the public repository. The effective date above identifies this published policy version.
